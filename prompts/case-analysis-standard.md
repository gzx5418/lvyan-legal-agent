# 案例分析标准（律言 — 本地知识库模式）

## 裁判规则知识库
律言内置常见纠纷的裁判规则模式，无需外部 API 即可提供类案分析。

### 本地裁判规则检索
```bash
python scripts/query_local.py -q "民间借贷 利息" --type case -o result.json
```

### 知识库文件
`knowledge/case_patterns.md` — 覆盖以下 6 大纠纷类型：
- 民间借贷纠纷
- 房屋租赁纠纷
- 劳动争议
- 买卖合同纠纷
- 离婚纠纷
- 交通事故纠纷

每种类型包含：典型裁判规则、常见争议焦点、常见败诉原因

### AI 模型补充
本地知识库未覆盖的纠纷类型，使用 AI 模型知识补充，标注来源。

## Analysis format
使用"总-分-总"结构：
1. 总：裁判趋势、胜诉率区间、关键影响因素
2. 分：逐条类案拆解（裁判要旨、与本案关联点）
3. 总：维权路径、证据补强、应对建议

## Win-rate rule
- 仅给区间，不给绝对值
- 示例：`45%-60%`
- 必须说明影响因素
