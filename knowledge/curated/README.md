# 律言本地法律知识库

本目录包含律言 Skill 的内置法律知识库，覆盖中国大陆法律体系中最高频的法律咨询场景。所有内容无需外部 API 即可使用。

## 文件索引

| 文件 | 覆盖领域 | 内容类型 | 条文/规则数 |
|------|---------|---------|-----------|
| `civil_code.md` | 民法典（总则、物权、合同、人格权、婚姻家庭、继承、侵权责任） | 法条原文 + 适用场景 | 82条 |
| `labor_law.md` | 劳动合同法、劳动争议调解仲裁法、工伤保险条例、工资支付规定 | 法条原文 + 适用场景 | 29条 |
| `consumer_and_tort.md` | 消费者权益保护法、食品安全法、网络侵权 | 法条原文 + 适用场景 | 15条 |
| `procedure_law.md` | 民事诉讼法、仲裁法、诉讼时效 | 法律要点 + 适用场景 | 25+要点 |
| `case_patterns.md` | 民间借贷、房屋租赁、劳动争议、买卖合同、离婚、交通事故 | 裁判规则模式 + 争议焦点 + 败诉原因 | 6大类 |
| `evidence_guide.md` | 举证责任、证据种类、电子证据、各纠纷证据清单 | 证据规则指南 | 4大类 |

## 检索方式

### 脚本检索
```bash
# 全库检索
python scripts/query_local.py -q "民间借贷 利息" -o result.json

# 仅检索法条
python scripts/query_local.py -q "租赁合同 押金" --type law

# 仅检索裁判规则
python scripts/query_local.py -q "交通事故 赔偿" --type case

# 仅检索证据规则
python scripts/query_local.py -q "举证责任 劳动" --type evidence
```

### AI Agent 直接查阅
Agent 在分析用户问题时，根据意图识别结果直接读取对应的知识文件：
- 用户问法条 → 优先查阅 `civil_code.md`、`labor_law.md`、`consumer_and_tort.md`
- 用户问案例/裁判规则 → 查阅 `case_patterns.md`
- 用户问证据 → 查阅 `evidence_guide.md`
- 用户问诉讼程序 → 查阅 `procedure_law.md`

## 数据来源

知识库内容参考了以下权威渠道，确保法条引用准确：
- **国家法律法规数据库**（https://flk.npc.gov.cn/）
- **人民法院案例库**（https://rmfyalk.court.gov.cn/）
- **中国裁判文书网**（https://wenshu.court.gov.cn/）
- **最高人民法院/最高人民检察院官网**

## 准确性说明

⚠️ **重要提示**：本知识库中的法条内容由 AI 模型根据训练数据编写，并非从权威网站逐条爬取验证。虽然条文号和核心法律要件力求准确，但可能存在以下情况：
1. **条文内容细微偏差** — 部分法条的表述可能与官方原文存在差异
2. **版本时效性** — 法律会有修订，训练数据可能未覆盖最新变更
3. **地方性法规未覆盖** — 仅收录全国性法律，地方性法规和司法解释需查阅权威来源

## 核对工具

项目提供了自动核对工具，可用于验证知识库内容：
```bash
# 1. 从国家法律法规数据库手动下载法律文件
# 2. 将文件放入 knowledge/crawl_cache/ 目录
# 3. 运行核对脚本
python scripts/verify_law_texts.py --extract --verify
```

## 使用建议

- **日常咨询**：知识库内容可作为快速参考
- **正式法律文书**：请通过国家法律法规数据库（https://flk.npc.gov.cn/）核对法条原文
- **诉讼案件**：建议咨询执业律师，以权威法律文本为准

## 更新说明

- 所有法条以最新修订版本为准
- 裁判规则基于公开裁判文书归纳，反映一般裁判倾向
- 地方性法规和司法解释未收录在内，如需请查阅上述权威来源
